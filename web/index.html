What is this?

Ticky is a small Python-like language whose compiler doesn't produce machine code: it produces a circuit for the game Factorio, built out of the game's combinators (little boxes that add, compare and pick numbers, wired together with red and green wires). Every program becomes a blueprint you can paste into the game.

You don't need the game to play with it here. Write a program on the left, and the playground compiles it as you type:

  • Problems: errors and warnings, also underlined in the editor.
  • Tests: test "…": blocks run in a tick-by-tick simulator of the game's circuits.
  • Summary: what the compiler built, and how big and fast it is.
  • Circuit: the actual layout: every box is a combinator, every line a wire. Hover for what each one does.

Things that look like Python mostly work like Python, with a twist: time is measured in game ticks (60 a second), every 30 ticks: runs a block periodically, wait until x pauses, and input/output declare the wires your circuit reads and writes. Pick an example from the menu to see more.

The source lives at github.com/trentmkelly/ticky; the language is described in its SPEC.md.
